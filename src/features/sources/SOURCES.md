# Sources

A source is an optional property of transactions and subscriptions.

## Transaction Entry Aid

The primary purpose of a source is to simplify adding new transactions. When entering a new transaction, it's important to know which transactions have already been recorded for that source. To help with this, we show the most recent transactions for the selected source. This allows you to find where you left off in the banking app.

## Import

Each source can have a bank, which decides how its transactions can be imported: from a bank statement, straight from the bank, or both. See [Import](../import/IMPORT.md).

## Order

Sources can be reordered in settings. The order is reflected everywhere the list of sources is displayed.
